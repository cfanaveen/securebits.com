# Securebits

Marketing site for Securebits — AI consulting, automation, and enterprise AI solutions.

Live domain (planned): [thesecurebits.com](https://thesecurebits.com)

## Stack

Static HTML/CSS. Hosted on Netlify. Contact form uses Netlify Forms (`name="contact"`).

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Netlify

- Publish directory: `.` (see `netlify.toml`)
- Form: `contact` → redirects to `/thank-you.html`
- Custom domain: `thesecurebits.com`
